## ⚠️ 2026-08-25 一面实测：这三题答砸了

| 页面 | 砸在哪 |
|---|---|
| [[Q4-Answer-Agent的决策空间]] | 说「工具由 skill 决定」「不设上限」「超时 33 分钟」——三个都错 |
| [[Q7-额度是拍的还是有数据]] | **编了数字**：「撞到过上限」「平均 5-6 次」。真实是 **0 次撞顶、平均 1.03** |
| [[Q8-检索跑题怎么判定]] | 说成「工具超时」+「LLM 判断」——两个都不是 |

**最贵的教训是 Q7**：编一个数字，他会追三个问题，每个都得用新的编造去圆。
而 2026-08-26 补跑统计后更讽刺——**真实数据自带一个漂亮结论（上限拍偏大了、我知道该降到几），比我编的数字好讲得多。**
**说「我没测过，但数据在哪、怎么测」，永远好过编一个平均值。**

## 这一串问题的逻辑链

他不是随机问的，是顺着一条线往下挖：

```
Q6 六步里哪几步是真 Agent？ → 考：敢不敢自己拆穿「multi-agent」   ← 第一道诚实性测试
 ↓ 只有分诊和 Answer
Q1 你有没有判断标准？       → 考：是不是把判断丢给模型就不管了
 ↓ 有标准
Q4 那 Answer 决策空间多大？ → 考：数字准不准
 ↓ 报出额度
Q7 这些数字是拍的还是测的？ → 考：会不会编数字            ← 陷阱题
 ↓ 承认是拍的
Q2 判错了能捞回来吗？       → 考：有没有兜底，还是单点依赖
 ↓ 有三道保险
Q8 那跑题重检靠什么信号？   → 考：简历写的功能说不说得出触发条件
 ↓ 词法重合率
Q3 保险也没接住呢？         → 考：知不知道保险丝哪儿会断     ← 真考点
```

（[[Q5-Answer-Agent是干什么的]] 是基本盘，不是他问的，但讲不清前面全白搭。）

**两个分水岭**：Q7 看你会不会编数字，Q3 看你知不知道自己的洞在哪。这两题答法比前面所有题加起来都重要。

## 跨页共用的三个结论（记这三条）

1. **「难度」判的是执行结构，不是主观难度。** 见 [[Q1-难度分诊的判据]]
2. **系统只检查「说的话有没有依据」，不检查「该说的有没有说全」。** 见 [[Q3-谁来发现漏答]]
3. **所有额度都是硬限；检索额度曾经紧到补查只有 1 次**，2026-08-28 放宽到 5 并改为触顶降级。见 [[Q4-Answer-Agent的决策空间]]
4. **凡是阈值和上限，全是拍的**，但现在至少工具调用分布是**测过的**（`python scripts/analyze_tool_calls.py`）。被问到：直说是拍的 + 设计意图 + 有数据就报数据并交代口径。见 [[Q7-额度是拍的还是有数据]]
5. **凡是「相关性 / 质量」判定，全是本地词法算的**，不是 LLM 判。快、免费、可复现，但不懂同义词。见 [[Q8-检索跑题怎么判定]]
